
# 💰 Meu Financeiro

O **Meu Financeiro** é um aplicativo de gestão financeira pessoal desenvolvido com HTML5, CSS3 e JavaScript. Com uma interface moderna, minimalista e responsiva, o projeto foi criado para facilitar o controle e a organização das finanças pessoais de forma simples, prática e gratuita.

## ✨ Funcionalidades

- 💵 **Controle de saldo:** informe o dinheiro disponível e acompanhe o saldo restante automaticamente.
- 🧾 **Registro de gastos:** adicione e exclua despesas, informando nome, valor e data.
- 📊 **Resumo financeiro:** visualize o saldo disponível, o total de gastos e o saldo restante.
- 📅 **Organização mensal:** selecione o mês de referência para organizar suas despesas.
- ⏳ **Pendências futuras:** registre compromissos financeiros separadamente, sem descontá-los do saldo atual.
- 💾 **Armazenamento local:** mantenha seus dados salvos no navegador por meio do LocalStorage.
- 📱 **Interface responsiva:** utilize o aplicativo em computadores e dispositivos móveis.
- ✅ **Validação de dados:** verifique as informações antes de cadastrar gastos e pendências.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** design, estilização e responsividade.
- **JavaScript:** cálculos automáticos, validações e gerenciamento dos registros.
- **LocalStorage:** armazenamento local dos dados no navegador.

## ⚙️ Funcionamento

O usuário informa o saldo disponível e registra suas despesas. O aplicativo soma os gastos cadastrados e subtrai o total do saldo inicial, atualizando automaticamente o valor restante.

As pendências futuras ficam em uma seção independente, permitindo organizar compromissos financeiros sem afetar o cálculo do saldo atual.

O aplicativo inicia sem lançamentos de exemplo, permitindo que cada usuário cadastre suas próprias informações.

## 🎯 Objetivo

Oferecer uma ferramenta acessível e intuitiva para ajudar na organização financeira pessoal, permitindo acompanhar despesas, controlar o dinheiro disponível e planejar compromissos futuros em um único lugar.

## 🔒 Armazenamento de dados

Os dados são armazenados localmente no navegador, sem necessidade de cadastro ou conexão com serviços financeiros externos. As informações não são sincronizadas automaticamente entre dispositivos e podem ser perdidas caso os dados locais do navegador sejam apagados.
